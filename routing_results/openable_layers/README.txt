Open these files if your GIS cannot load the competition-format GeoJSON.
best_lines.geojson: only new heat network LineString features for the best variant.
best_points.geojson: tie-in and heat chamber Point features for the best variant.
best_lines_minimal.geojson: minimal line attributes for strict web map importers.
best_points_minimal.geojson: minimal point attributes for strict web map importers.
best_spatial.geojson: best variant without null geometry summary records.
ranked_lines.geojson / ranked_points.geojson: top ranked variants split by geometry type.
No CRS member, geometry=null features, null properties, or array/dict property values are included here.
