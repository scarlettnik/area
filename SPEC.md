# §V
- V1: Один путь от подключённой цели до существующей сети; без циклов, транзита через потребителя и пересечений вне общего узла.
- V2: Подключения приоритетны; допустимый найденный маршрут не отбрасывать ради меньшей цены.
- V3: Реальный ДУ по расходу, непрерывной длине и downstream ДУ; на постоянном расходе не менять ДУ; камеры не обнуляют длину.
- V4: Отступы от внешнего габарита по ДУ; финальный прямой ввод через ближайшую границу только собственного полигона; поворот ≤90°.
- V5: Разветвление только в камере; суммарная степень с существующими линиями ≤4; правило существующей камеры в пределах 10 м.
- V6: Новая камера включает присоединение; существующая камера — 5 млн за каждый новый линейный участок; реконструкции нет.
- V7: construction_cost включает трубы, новые камеры и врезки; calculated_cost добавляет только штраф; score использует только новую длину.
- V8: 2D depth=null/K=1; depth отдельный режим; special прямой, разрезан по составу зон; K=max; угол дороги по границе входа.
- V9: Точные концы, действительные ссылочные ID, исходный тип ID неподключённых целей; нет tie_in/reconstruction объектов.
- V10: Финальный rank строго по score; структурно разные варианты; refinement не ухудшает сохранённый результат.
- V11: Независимая проверка восстанавливает потоки, степени, длины, расходы и стоимость; координаты могут быть записаны в обоих направлениях.
- V12: DN-aware поиск повторно проверяет общий ствол после роста расхода; экспорт только после валидатора.
